LLM Guides (LMP v2.0)

These guides are written specifically for AI assistants and Large Language Models. They explain how to read, write, and reason about LMP (Lean Musical Protocol) in plain language, with token-efficient examples and constraints tailored for model consumption.

Specification Guides

  • Master All-in-One Spec ⭐ Recommended for LLMs — The primary recommended specification for LLMs (ChatGPT, Claude, Gemini, Cursor). Full multitrack composition rules with chords, basslines, melodies, drums, and syntax rules in a single comprehensive context file.
  • General Guide Modular — Lightweight context footprint (~2,200 tokens) covering core LMP headers, tracks, events, syntax rules, and protocol basics for single instruments.
  • Melodic & Chords Guide Modular — Optimized for pitched, melodic instruments. Covers GM melodic patches, SPN note names, velocity, duration, polyphonic voice leading (+), and legato.
  • Percussive & Drums Guide Modular — Optimized for drums. Covers standard GM percussion, repeating drum loops (1.0-5.0:1/2), modifiers (| R, | V), and dynamic accents.
