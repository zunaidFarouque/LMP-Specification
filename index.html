🎵 What is LMP v2.0?

The Lean Musical Protocol (LMP) is a stateful, Space-Separated Value (SSV) grid format designed as the ideal bridge between AI models and binary MIDI data.

Unlike verbose JSON (which exhausts context windows) or primitive sheet-music notations like ABC (which cannot express modern multitrack DAW production), LMP is built from the ground up for bidirectional LLM interaction: AI models can read, analyze, and write mathematically precise compositions with minimal token overhead.

The Bidirectional Pipeline

  1. MIDI ➔ LMP ➔ AI (Contextual Analysis): An LMP decompiler converts binary .mid files into compressed LMP text. LLMs analyze multitrack arrangements, chord progressions, and rhythms using ~75% fewer tokens than raw representations.
  2. AI ➔ LMP ➔ MIDI (Generative Output): The LLM writes LMP syntax. The zero-sandbox compiler deterministically transforms this text into standard binary MIDI in milliseconds.

🚀 What's New in v2.0

  • Tokenizer-Native "Postel's Law" Parsing: Tolerates natural spaces in chords (e.g. 1.0 C4, E4, G4), strips markdown code fences, and heals continuation lines without syntax crashes.
  • Deterministic Seeded PRNG Humanization: @SEED <int> paired with @RULE VEL=min-max guarantees 100% bit-for-bit identical MIDI compilation while adding natural velocity groove.
  • Official MCP Server (@lmp-midi/mcp): Native Model Context Protocol support for Claude Desktop, Cursor, Gemini, and autonomous agent loops (compile_lmp, decompile_midi, validate_lmp).
  • Lossless Bidirectional Decompiler: High-precision conversion from .mid back to clean LMP, preserving multi-line polyphony (+) and conductor tracks.
  • Next-Gen Web Studio: In-browser procedural WebAudio synthesis, multi-track mixer, live syntax linter, and AI Musical Friend copilot.
